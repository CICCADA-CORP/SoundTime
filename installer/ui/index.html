        Besoin d’aide ?

        Sur quelle machine installer SoundTime ?

        Lancez l’assistant sur votre ordinateur, puis choisissez cet appareil ou une machine distante. Seule la machine qui héberge SoundTime doit rester allumée pendant l’écoute.

        À quoi sert Docker ?

        Docker exécute SoundTime et conserve les données de votre bibliothèque. Installez Docker Desktop sur Mac ou Windows, ou Docker avec Compose sur Linux. Un NAS peut utiliser son gestionnaire de conteneurs. Le projet à importer se prépare depuis un ordinateur sans Docker.

        Guide officiel de Docker

        Comment écouter sur mon téléphone ?

        Dans le mode personnalisé, choisissez l’accès sur votre réseau. Après la création de votre compte, activez cet accès dans l’assistant. Ouvrez l’adresse réseau sur votre téléphone connecté au même Wi-Fi.
