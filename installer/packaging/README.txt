SoundTime CLI
=============

Extract the entire archive and open a terminal in the extracted folder.
Keep the bin folder alongside the launcher.

macOS / Linux          ./soundtime
Windows PowerShell     .\soundtime.cmd
Windows cmd            soundtime.cmd

Choose "This computer" to install locally or "Another machine" for SSH
deployment or a NAS project. The wizard will show the settings for review
before installing. Add --help to list the available commands.

Installation guide: https://github.com/CICCADA-CORP/SoundTime/blob/main/docs/installateur.md
